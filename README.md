# Установка / Installation
Файл .zip - версия для пк. Дабы установить, скачайте файл, создайте новую папку и распакуйте архив в неё.

Файл .apk - версия для андроид. Дабы установить, скачайте файл, затем просто откройте его и установите.

Есть метод установки с модами - скачайте Geode, установите его в зависимости от платформы, зайдите в Geometry Dash, найдите мод GDPS Switcher, скачайте его и перезапустите игру. Снизу появится новая кнопка, нажимаем на неё, в открывшемся меню нажимаем New, в поле с названием пишем "Nova GDPS" (без кавычек), а в поле ниже вставляем следующую ссылку: "https://novagdps.ps.fhgdps.com/" (без кавычек), строку Save Name не трогаем, затем нажимаем сохранить, затем выходим, нас просит перезапустить игру, перезапускаем. Всё! Мы на сервере! С модами!

Установите текстур пак сервера для этого метода следующим образом: найдите мод Texture Loader, скачайте его, для андроид обязательно ещё скачайте мод High Graphics on Mobile, затем перезапустите игру, выйдите из неё, а далее скачайте текстур пак по ссылке https://drive.google.com/file/d/1y55y7CFoWMMsLghpqPcPscz43jRBljmp/view?usp=sharing, а затем:
На андроид: заходите в Android/media/com.geode.loader/game, далее кака на пк
На пк: заходите в корневую папку игры, затем заходите в geode/config/geode.texture-loader/packs, перемещаете текстур пак в эту папку.
Затем заходите в игру, нажимайте кнопку с изображением папки, которая находится справа, затем нажимаете Ok в появившемся окне, затем нажимаете настройки, Graphics, Textures, находите Nova GDPS TexturePack.zip, перетаскиваете его в правый столбец и нажимаете Apply. Всё! Текстур пак применён!

ВНИМАНИЕ! Geode может быть доступен на новые версии клиента не сразу, так что придётся подождать.

The .zip file is a version for PC. In order to install, download the file, create a new folder and unzip the archive into it.

The .apk file is a version for Android. In order to install, download the file, then just open it and install it.

There is an installation method with mods - download Geode, install it depending on the platform, go to Geometry Dash, find the GDPS Switcher mod, download it and restart the game. A new button will appear from below, click on it, click New in the menu that opens, type "Nova GDPS" (without quotes) in the name field, and paste the following link into the field below: "https://novagdps.ps.fhgdps.com/" (without quotes), do not touch the Save Name line, then click save, then exit, it will ask to restart the game, restart. That's it! We are on the server! With mods!

Install the server texture pack using this method as follows: find the Texture Loader mod, download it, be sure to download the High Graphics on Mobile mod for android, then restart the game, exit it, and then download the texture pack from the link https://drive.google.com/file/d/1y55y7CFoWMMsLghpqPcPscz43jRBljmp/view?usp=sharing and then:
On android: go to Android/media/com.geode.loader/game, then follow steps for pc
On PC: go to the root folder of the game, then go to geode/config/geode.texture-loader/packs, move the texture pack to this folder.
Then go into the game, click the button with the image of the folder on the right, then click Ok in the window that appears, then click settings, Graphics, Textures, find Nova GDPS TexturePack.zip, drag it to the right column and click Apply. That's it! The texture pack is applied!

NOTE! Geode may not be available on new client versions right away, so you’ll have to wait.
